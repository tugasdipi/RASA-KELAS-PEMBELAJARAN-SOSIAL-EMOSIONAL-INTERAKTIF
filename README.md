# RASA KELAS V7.23 — GitHub Pages (di bawah 25 MB)

Website RASA KELAS lengkap dengan lima misi interaktif, gambar embedded, dan Piagam Kelas PNG.

## Cara deploy
1. Ekstrak ZIP ini.
2. Upload `index.html`, `.nojekyll`, dan `README.md` ke root repository GitHub.
3. Settings > Pages > Deploy from a branch > `main` > `/(root)` > Save.

Semua fitur situs berasal dari V7.23. Sebagian ilustrasi latar dan cerita empati disimpan dalam format WebP berkualitas tinggi untuk mengecilkan ukuran HTML.
